# 🎮 GameVault

GameVault is a simple web application that allows users to discover and search for free-to-play video games.

## 📌 Features

- Display free-to-play games using the FreeToGame API
- Search for games by name
- Filter games by genre
- Display game information such as:
  - Game title
  - Platform
  - Genre
  - Publisher
  - Release date
  - Game image
- Responsive design for different screen sizes

## 🛠️ Technologies Used

- HTML
- CSS
- JavaScript
- FreeToGame API

## 🌐 API Used

FreeToGame API

https://www.freetogame.com/api
